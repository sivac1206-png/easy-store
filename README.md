# Easy Store — Flutter Grocery Delivery MVP

A clean, runnable Flutter starter for a quick-commerce grocery app.

## Included
- Home dashboard
- Category browsing
- Product search/filter
- Product details
- Cart with quantity controls
- Checkout/address/payment selection
- Order confirmation
- Order tracking timeline
- Profile screen
- Provider-based cart state
- Sample grocery catalog (no backend required)

## Run
1. Install Flutter 3.x and Android Studio/Xcode as appropriate.
2. Create a Flutter project or use this source tree.
3. Run:
   flutter pub get
   flutter run

## Build
Android APK:
    flutter build apk --release

iOS:
    flutter build ios --release
